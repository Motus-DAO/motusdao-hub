# Formulación de casos e hipótesis clínicas

# Función dentro de la ruta

Segundo curso de la mini-ruta clínica de Benjamín Buzali dentro de Praxis.

Parte de las observaciones y patrones trabajados en:

**Escucha clínica y patrones relacionales.**

# Problema que aborda

El psicólogo puede reunir información relevante de una sesión y aun así tener dificultades para:

- Organizarla.
- Distinguir observaciones de interpretaciones.
- Establecer relaciones entre datos.
- Construir una hipótesis provisional.
- Buscar evidencia que la apoye o contradiga.
- Presentar el caso con claridad.
- Llegar preparado a discusión o supervisión.

# Resultado educativo principal

Al terminar, el participante podrá organizar observaciones clínicas, construir hipótesis provisionales, buscar evidencia a favor y en contra y preparar una formulación para revisión o discusión.

# Audiencia

# Principios pedagógicos

- Las hipótesis se presentan como provisionales y revisables.
- Se distingue claramente observación, inferencia e interpretación.
- Se busca evidencia a favor y en contra.
- Se explicitan límites y vacíos de información.
- No se usa una hipótesis como sustituto de evaluación profesional.
- No se presenta la lógica de Benjamín como el único método válido de formulación.

# Relación con supervisión

El curso puede preparar al participante para:

- Organizar el material de un caso.
- Formular preguntas.
- Explicar cómo llegó a una hipótesis.
- Reconocer qué información falta.
- Presentar alternativas.

No sustituye supervisión clínica ni produce aprobación automática dentro de MotusDAO.
